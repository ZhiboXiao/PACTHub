内容与来源

样本集合

data/samples.json 记录八个代表样本及其视图。data/display-provenance.json 记录源文件名、SHA-256 与图像转换过程。

连续成像

data/temporal.json 记录测量时刻、显示窗、区域坐标及原始与相对读数。data/temporal-readouts.csv 提供相同读数的表格形式。

生成与验证

scripts/prepare_showcase.py 读取已审核的配图数据；register_temporal.py 完成配准与读数；build_sample_views.py 生成带比例尺的多视图；build_q_video.py 绘制 Q 视频。scripts/validate_site.py 检查数据一致性、资源链接、元数据及转换记录。

Content and provenance

Specimen collection

data/samples.json records eight representative specimens and their views. data/display-provenance.json records source filenames, SHA-256 hashes and image conversions.

Temporal imaging

data/temporal.json records measured times, display windows, region coordinates and linear and relative readouts. data/temporal-readouts.csv provides the same measurements as a table.

Preparation and validation

scripts/prepare_showcase.py reads the audited figure sources; register_temporal.py registers frames and recomputes readouts; build_sample_views.py prepares scaled views; build_q_video.py renders the Q video. scripts/validate_site.py checks data consistency, resource links, metadata and conversion records.
