项目说明

定位

PACTHub 以数据集、benchmark 和 pipeline 为核心。代表样本涵盖旋转小鼠、扫描小鼠、叶片、人手、小鼠脑、背侧全躯干小鼠、单次曝光肝脏、方形靶仿体与两组连续成像。

使用入口

样本详情可切换深度、灰度及三维视图，并放大查看。连续成像支持逐帧浏览、自定义框选、移动和缩放区域，实时计算强度曲线。

资源状态

代表性样本已存档于 Zenodo，采用 CC BY 4.0。网站 05 提供 Zenodo、Google Drive、代码和引用入口。

Project guide

Purpose

PACTHub centres on a dataset, a benchmark and a reconstruction pipeline. The showcase covers rotation and scanned mouse acquisitions, leaf, hand, mouse brain, a dorsal whole-trunk mouse volume, single-exposure liver and square-target phantom specimens, and two independent image sequences.

Explore the data

Sample details offer depth, intensity and 3D views with image enlargement. Temporal imaging supports frame-by-frame navigation and live intensity traces from regions that users draw, move and resize.

Resource status

Representative samples are archived on Zenodo under CC BY 4.0. Section 05 provides Zenodo, Google Drive, code and citation links.
