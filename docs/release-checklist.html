资源发布说明

数据引用

使用本数据集，请引用数据记录与数据集论文。数据记录：Xiao, Z. (2026). PACTHub [Data set]. Zenodo. 10.5281/zenodo.23496053。数据集论文的 arXiv 链接与引用将在发布后补充。

当前可用

八个样本的多视图展示；两组共 36 个测量时刻的图像、自定义区域与实时强度曲线；重建和评测流程说明。

完整数据发布

完整 RF 数据包需附采集参数、探测器坐标、重建配置、文件校验和、数据许可与正式引用。网站资源入口由 data/site-config.json 的实际链接管理。

维护检查

更新数据时同步图像、数值、坐标与来源记录，检查中英文界面、移动端、逐帧联动和所有下载路径。

Release information

Dataset citation

If you use the dataset, please cite the data record and dataset paper. Data record: Xiao, Z. (2026). PACTHub [Data set]. Zenodo. 10.5281/zenodo.23496053. The arXiv link and paper citation will be added when published.

Available now

Multi-view displays for eight specimens; 36 measured timepoints across two sequences with interactive region selection and live intensity traces; reconstruction and evaluation documentation.

Full dataset release

Full RF data packages include acquisition parameters, detector coordinates, reconstruction settings, checksums, data licence and formal citation. Resource availability is controlled by the actual links in data/site-config.json.

Maintenance checks

When updating data, synchronize images, measurements, coordinates and provenance. Check both languages, mobile layout, frame synchronization and every download path.
