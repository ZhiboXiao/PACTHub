发布前检查清单

适用于网站首次公开、数据版本更新和算法资源接入。当前交付是本地网站框架；数据标准化与 AI 算法已由项目方完成，下面检查的是公开材料、网站映射及发布条件。没有证据的项目保持“待核实”，不要勾选。

网页版清单为只读参考，不保存审核状态；请在项目自己的发布记录中保存检查结果、证据与负责人。

1. 公开范围与身份

2. 数据与索引映射

3. 伦理、隐私与去标识化

此清单是发布操作提醒，不替代机构审批、数据治理或专业法律意见。

4. 许可、作者与引用

5. 数据托管与下载

此清单记录的 GitHub Pages 已发布站点上限为 1 GB，月带宽软限制为 100 GB；实际发布前再次查看官方限制。普通 Git 文件也受平台限制，大型扫描与权重应另行规划托管。

6. 已有算法的网站接入

详见算法接入指南。

7. 页面质量与可访问性

8. 最终发布和验证

未完成的检查应列出负责人及需要的材料。若决定先发布框架预览，应保留明显的 DEMO 与待接入标记，不能宣传为真实数据集已开放下载。

Pre-release checklist

Use this checklist for the first public website release, data-version updates, and algorithm-resource integration. The current deliverable is a local website framework. The project team has already completed data standardization and the AI algorithm. These checks cover public materials, website mapping, and release conditions. Leave unsupported items as “Pending verification”; do not check them off.

The website checklist is a read-only reference and does not save review status. Keep findings, evidence, and responsible people in the project's own release record.

1. Public scope and identity

2. Data and index mapping

3. Ethics, privacy, and de-identification

This checklist is an operational release reminder, not a substitute for institutional approval, data governance, or professional legal advice.

4. Licenses, authorship, and citations

5. Data hosting and downloads

The limits recorded in this guide are 1 GB for a published GitHub Pages site and a soft monthly bandwidth limit of 100 GB. Check the official limits again before deployment. Ordinary Git files also have platform limits; plan separate hosting for large scans and weights.

6. Website integration of the existing algorithm

See the algorithm integration guide.

7. Page quality and accessibility

8. Final release and verification

For unfinished checks, identify the responsible person and required materials. If releasing a framework preview first, retain prominent DEMO and pending-integration labels. Do not advertise it as a real dataset already open for download.
