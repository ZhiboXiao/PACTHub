从 PAdata 到三维体

标准流程为 PAdata → 参数核对与预处理 → FOV 选择 → 声速选择 → BP／MB 重建 → 数值三维体与 MIP。每个采集沿用已发布的 sample_metadata.json 和 reconstruction_parameters.json。

两份参数文件

sample_metadata.json 核对采集编号、FTC 存储轴、形状和帧数；reconstruction_parameters.json 提供信号、几何、FOV、声速及重建设置。探测器坐标可从 Calibration 文件内嵌到同一 JSON；MB 参数保存在 defaults.mb。

FOV 与声速

可直接沿用记录的视野和声速，也可开启自动选择。FOV 在大视场 BP 上估计 XY 中心与长轴；声速选择对固定帧、几何和预处理扫描候选声速。输出保存候选得分及本次生效的参数副本。

BP 与 MB 输出

默认使用公开文献 UBP，预处理保留原带通、能量归一化和截取顺序；MB 使用有限圆盘前向／伴随模型。MB 同时生成使用相同预处理 RF 的 BP_matched。三维体按 ZYX 保存，坐标单位为 mm；显示窗独立于定量数据。

运行与网页展示

下载采集数据与代码后，在本机或 GPU 服务器运行。网页提供样本展示、操作说明和下载入口。重建得到的数值体可进一步生成统一显示窗、物理范围和比例尺的展示资源。

小鼠 Q 实例

第 06 章使用论文中的小鼠 GT 与待评估图像。三维计算依次展示局部背景、正对比度、参考定义的弱／强区域和结构重叠，Q = 82.53。

评测

PSNR、全图 SSIM 和 L1 描述整体误差与相似度。结构质量 Q 提供补充，关注高能量血管区域及弱结构。比较时统一空间对齐、评测范围、参考体及强度约定。

Q 计算视频

51 秒视频依次展示配对输入、正局部对比度、参考管状支撑、弱强分组、结构重叠与实测小鼠。Q = 100√(Dweak Dstrong)，每组 D = 2Σmin(g·hX,hR)/Σ(g·hX+hR)。全部计算在三维体上进行，投影用于展示。

展示与定量

展示图可使用独立线性窗；定量指标在预先定义的数值数据上计算。连续成像对每个用户选框使用跨时刻相同的有效像素，保留所有测量时刻。各时刻共享显示窗。

From PAdata to 3D volumes

The standard workflow is PAdata → validation and preprocessing → FOV selection → sound-speed selection → BP / MB → numerical 3D volumes and MIPs. Each acquisition uses its published sample_metadata.json and reconstruction_parameters.json.

Get the code

Download the workflow and interfaces ↓ · Source and complete guide on GitHub ↗. The archive contains PAdata/JSON interfaces, preprocessing, MB, workflow pseudocode and tests. The package includes a public literature UBP. The actual internal BP program is confidential and is not distributed. Its README provides installation commands, execution steps and the input contract.

Two parameter files

sample_metadata.json checks the acquisition ID, FTC storage axes, shape and frame count. reconstruction_parameters.json supplies signal, geometry, FOV, sound-speed and reconstruction settings. Detector coordinates can be embedded from the Calibration file into that JSON; MB settings are stored in defaults.mb.

FOV and sound speed

Retain the recorded FOV and sound speed or enable selection. Large-FOV BP estimates the XY centre and long axis. Sound-speed selection scans candidates with fixed frames, geometry and preprocessing. Outputs include candidate scores and an effective parameter pair for replay.

BP and MB outputs

Public literature UBP is connected by default, with the recorded bandpass, energy normalization and crop order. MB uses a finite-disk forward/adjoint model. MB also exports BP_matched with identical preprocessed RF. Volumes use ZYX order and millimetre coordinates; display windowing is separate from numerical data.

Computation and website display

Download the acquisition data and code, then run reconstruction on a local machine or GPU server. The website provides sample displays, instructions and downloads. Numerical outputs can then be prepared as display assets with defined windows, physical bounds and scale bars.

Measured-mouse Q

Chapter 06 uses the manuscript mouse GT and test image. The 3D calculation extracts local background, positive contrast, reference-defined weak/strong support and structural overlap, giving Q = 82.53.

Evaluation

PSNR, full-image SSIM and L1 measure overall error and similarity. Structural quality Q complements them by examining high-energy vascular regions and weak structures. Comparisons share spatial alignment, evaluation domain, reference volume and intensity conventions.

Q calculation video

The 51-second video follows paired input, positive local contrast, reference tubular support, weak/strong groups, structural overlap and a measured mouse. Q = 100√(Dweak Dstrong), with D = 2Σmin(g·hX,hR)/Σ(g·hX+hR) in each group. Calculations use 3D volumes; projections illustrate the steps.

Display and quantification

Display images may use independent linear windows; metrics are calculated on the predefined numerical data. Each user-selected temporal region uses the same valid pixels across all measured timepoints. One display window is shared throughout the sequence.
